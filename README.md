Local Development
Clone Repository
git clone https://github.com/divsvash/portfolio-final.git
cd portfolio-final
Install Dependencies
npm install --legacy-peer-deps
Start Development Server
npm run dev
Production Build
npm run build

Preview production build locally:

npm run preview
